# 隐私说明

一句话：**这个项目没有服务器。** 你的东西要么在你浏览器里，要么直接发给你自己配的模型服务商。

下面说清楚每一类数据具体去了哪里。

---

## 你的 API key

**存在哪**：浏览器的 localStorage，键名 `frame.config.v1`。

**发给谁**：只发给你自己填的那个接口地址（通过本机的 Next.js 进程转发，见下）。

**不会发给**：项目作者、任何第三方、任何统计服务。

**风险**：localStorage 里的东西，同源的脚本能读到。所以：

- 别在公用电脑上用
- 别把带 key 的浏览器 profile 同步到云盘
- 「导出配置」时会自动把 key 抹掉，所以导出的内容可以放心贴给别人排查问题

---

## 你的对话内容

**存在哪**：只在浏览器内存里。关掉标签页就没了。

**发给谁**：发给你自己配的模型服务商（OpenAI / DeepSeek / 硅基流动 / 你本机的 Ollama……）。
这是对话能进行下去的前提。

**转发路径**：浏览器 → 本机的 `/api/chat` → 服务商。
多这一跳是为了绕开 CORS（不是每家服务商都开了跨域），不是为了经过第三方。
本地跑的时候这一跳就在你自己电脑上，请求不出本机就直接转走了。

**注意**：你配的服务商能看到你的对话内容，这是它的服务条款决定的，不是这个项目能改变的。
在意的话用 Ollama 那一档，模型跑在你自己电脑上。

---

## 记忆

**存在哪**：浏览器的 localStorage，键名 `frame.memory.v1`。

**发给谁**：每次对话时会拼进系统提示词，所以会跟着请求发给模型服务商。
发给模型的只是**摘要**（事实全带，历史摘要最多三条，总量超过 1200 字符就截断），
不是全部记忆原文。

**你能控制**：「记忆」标签页里能看到每一条、能单条删、能一键清空、能导出成 JSON。

**关掉**：记忆开关一关，一个字都不注入，也不写入。

---

## 操作流水

**存在哪**：浏览器内存里。关掉标签页就没了。

**内容**：调用了哪个工具、参数是什么、用户批没批准、结果如何。最多留 200 条。

**注意**：参数里可能包含你让 AI 处理的文件名或路径。如果这些算敏感信息，刷新页面就清掉了。

---

## 抓取的网页

`fetch_url` 工具抓回来的正文会交给模型处理，也就是会发给你配的服务商。

抓取时有 SSRF 防护：回环地址、内网段、云元数据地址（`169.254.169.254`）默认全部拦掉。
本机运行时会放开 localhost，方便连你自己跑的 Ollama —— 这个口子只在请求的 Host 是本机时打开。

---

## 不收集的东西

明确说清楚，这个项目**没有**：

- 没有统计埋点
- 没有错误上报
- 没有崩溃收集
- 没有用户账号体系
- 没有云端数据库

代码里没有任何一处会把数据发往项目作者控制的地址。想核实的话，
全局搜 `fetch(` 就三处：`/api/chat`、`/api/models`、`/api/tools`，都是本机地址。

---

## 部署到公网时要注意什么

如果哪天你把它部署到 Vercel 之类的地方：

1. **`/api/chat` 会变成真正的代理**。它会把你指定的地址转发过去，所以一定要有访问控制，
   否则可能被人当成开放代理用。代码里已经做了地址校验，但公网部署前请自己审一遍。
2. **localStorage 里的 key 还是在你浏览器里**，服务端不落盘。这一点不变。
3. **抓网页的接口也一样**，公网环境下要收紧 SSRF 防护的范围。

---

## 一句话总结

| 数据 | 在哪 | 谁能看到 |
| --- | --- | --- |
| API key | 你的浏览器 | 你、你配的服务商（作为鉴权） |
| 对话内容 | 浏览器内存 | 你、你配的服务商 |
| 记忆 | 你的浏览器 | 你、你配的服务商（摘要形式） |
| 操作流水 | 浏览器内存 | 只有你 |
| 抓回的网页 | 不落盘 | 你、你配的服务商 |
